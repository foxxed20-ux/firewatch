# Внешние модели для разработки FireWatch

По запросу владельца проекта рабочие агенты могут передавать ограниченные задачи
внешним моделям через `tools/ask_external_model.ps1`. Это инструмент разработки;
он не участвует в inference, сервисе, обучении или пользовательском интерфейсе FireWatch.

## Проверка 19 сентября 2026 года

| Провайдер | Проверенная модель | Фактический результат |
| --- | --- | --- |
| DeepSeek | `deepseek-flash` | HTTP 200, сгенерирован ответ `OK` |
| xAI / Grok | `grok-4.20-0309-non-reasoning` | HTTP 200, сгенерирован ответ `OK` |
| OpenAI | `gpt-4.1-mini` | Ключ принят `/models`, генерация: HTTP 429, `credit_balance_exhausted` |

В helper доступны только проверенные DeepSeek и xAI. Ключ OpenAI не активирован:
для генерации требуется пополнение API-счёта и повторная проверка.
Указанный статус — результат проверки в эту дату, а не гарантия доступности в будущем.

## Вызов из PowerShell

Из корня проекта подготовьте UTF-8 файл с конкретным вопросом и нужными фрагментами:

```powershell
New-Item -ItemType Directory -Path var/agent-llm -Force | Out-Null
# Используйте уникальный файл для своей задачи; var/ исключён из Git.
'Проверь предложенный контракт: ... Верни только существенные замечания.' |
    Set-Content -LiteralPath var/agent-llm/my-task.txt -Encoding utf8
powershell -NoProfile -File tools/ask_external_model.ps1 `
    -PromptFile var/agent-llm/my-task.txt -MaxTokens 1200

# Вторая модель, когда нужна независимая проверка:
powershell -NoProfile -File tools/ask_external_model.ps1 `
    -Provider xai -PromptFile var/agent-llm/my-task.txt -MaxTokens 1200
```

Вывод — JSON с `content`, `usage`, `finish_reason` и `truncated`. При ошибке процесс
завершается с кодом 1. `truncated: true` означает, что ответ обрезан лимитом;
не считайте такую проверку завершённой. Не повторяйте запрос автоматически после
таймаута: провайдер мог уже выполнить и тарифицировать его.

По умолчанию используется DeepSeek без thinking, до 1200 выходных токенов и 60 секунд.
Верхние границы: 4096 выходных токенов, 120 секунд, 64 KiB входного файла. Это лимиты
одного запроса, не общий денежный бюджет. Автоматических повторов, fallback и обхода
репозитория нет. Скрипт отправляет только явно указанный файл и краткую служебную
инструкцию выбранному официальному API. URL и модели фиксированы в helper.

## Работа агентов

- Передавайте внешней модели самостоятельные небольшие задачи: ревью фрагмента,
  черновик функции, поиск пропусков в контракте или вариант текста документации.
- Прикладывайте только нужный контекст; не отправляйте весь репозиторий, историю
  диалога, ключи, `.env`, приватные данные или credential-файлы.
- Не делайте дополнительный запрос, если локальная команда уже решает вопрос.
- Проверяйте предложения по исходникам и реальными тестами. Ответ внешней модели
  не выполняется как команда и не применяется к файлам автоматически.
- Не создавайте дополнительные Codex-задачи или копии полного контекста ради
  небольших вопросов, которые можно решить этим helper.

## Локальное хранение и учёт

Рабочие ключи находятся вне репозитория в
`%LOCALAPPDATA%\FireWatch\agent-api\deepseek.clixml` и `xai.clixml`.
Это SecureString, зашифрованные Windows DPAPI для текущего пользователя;
При локальной установке 19 сентября 2026 года ACL каталога был ограничен этим
пользователем и SYSTEM; helper сам не устанавливает ключи и ACL. Не копируйте эти файлы
в репозиторий или сообщения агентам. На другом ПК/под другой учётной записью нужна
отдельная установка ключей. Helper не устанавливает глобальные переменные среды
и не меняет аутентификацию Codex.

`%LOCALAPPDATA%\FireWatch\agent-api\usage\` содержит отдельные JSON с моделью,
временем, HTTP-статусом и фактическими token usage, без текста запросов/ответов.
Первичные результаты проверки находятся рядом в `*.status.json`.

API-вызовы используют баланс соответствующего провайдера. Активные управляющие
агенты Codex продолжают расходовать лимит подписки; этот helper не переключает
их модель или оплату. Экономия недельного лимита не измерена и не гарантируется.

Официальные контракты:
[DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/),
[xAI](https://docs.x.ai/developers/model-capabilities/legacy/chat-completions),
[аутентификация и тарификация Codex](https://learn.chatgpt.com/docs/auth).
