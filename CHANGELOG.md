# История изменений

Записи отражают законченные этапы; датами коммитов управляет Git. Итоговые метрики относятся к конкретному bundle и не переносятся на последующие версии автоматически.

## Правила сопровождения репозитория · 19 сентября 2026

- Для собственного кода выбрана Apache-2.0; добавлены полный текст `LICENSE` и уведомления `NOTICE`.
- Добавлены политика безопасности и кодекс поведения с подтверждённым приватным контактом команды. Уточнены обращения, ревью и ожидания по ответам в правилах участия.
- README связывает документы сообщества, каналы поддержки и условия использования сторонних материалов.
- Добавлена отдельная упаковка `v3-licensed` с `LICENSE`, `NOTICE` и новым manifest. Все 124 исходных файла сохранены побайтно; исторический архив v3 и его SHA-256 не изменены. Будущие сборки модельного архива обязательно включают лицензионные уведомления.
- Платформа организаторов приняла проверенный CSV V3 и показала результат **0,7319** со статусом `completed`. Разделение public/private и компоненты метрики не раскрыты; внутренняя validation-оценка остаётся отдельным измерением.

## Поиск спутниковых сцен · 19 сентября 2026

- Добавлены опциональная подложка Google Maps и ограниченные по области/периоду API поиска и RGB-предпросмотра Sentinel-2 через Earth Engine.
- Проверены 17 frontend-тестов, 69 сервисных тестов, реальные EE search/preview/тайлы и локальный интерфейс на desktop/mobile. [Сводка проверки исходников](docs/evidence/google-imagery-20260919.json).

## Конкурсная поставка v3 · 19 сентября 2026

- Завершено сравнение CNN, LightGBM и XGBoost. Выбраны отдельные ансамбли CNN/LightGBM для AF и BS; validation Score 0,707178 с раскрытыми ограничениями выбора.
- Полный offline CLI обработал 269 чипов за 390,7 с на GPU T4, сформировал 447 строк данных. CPU replay всех 129 validation-чипов воспроизвёл три компонента метрики без изменения.

- Обновлены паспорт команды, исследование, технический отчёт, презентация и снимок публичной карты.
- Добавлены фиксация происхождения данных/исходников и неизменяемая публикация архивов с SHA-256. Локальные наборы: 22 модельных, 30 сервисных и 4 frontend-теста.
- Репозитории GitVerse (`main` и `master`) и GitHub (`main`) синхронизируются с сохранением реальной истории разработки.
