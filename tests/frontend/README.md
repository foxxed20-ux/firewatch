# Проверка интерфейса

Фронтенд — статические `web/index.html`, `styles.css`, `core.js`, `app.js`.
FastAPI раздаёт их без сборки и npm-зависимостей.

## Быстрые проверки

```powershell
node --check web/app.js
node --test tests/frontend/core.test.cjs
```

Проверяются включённая конечная дата UTC, валидность области, пересечения
полигона и сохранение различия между нулём и отсутствием данных.

## Браузерные сценарии

```powershell
python tests/frontend/fixture_server.py
```

Открыть `http://127.0.0.1:8091/?scenario=success`. Это отдельный локальный
стенд с явно обозначенными тестовыми данными, а не демонстрационная модель.
Варианты `scenario`:

| Сценарий | Ожидаемый результат |
| --- | --- |
| `success` | Очередь → анализ → результат, 2 точки, 12,5 га, слои и GeoJSON |
| `partial` | Видимое предупреждение о частичном покрытии, BS 50% |
| `no_data` | Прочерки в метриках, объяснение отсутствия наблюдений |
| `failed` | Ошибка обработки и доступная форма нового анализа |
| `missing_job` | Ошибка 404 и доступная форма нового анализа |
| `unavailable` | Модель готовится; запуск недоступен |
| `auth` | Запрос токена; тестовый токен `qa-test-token` |
| `post_retry` | Первый POST 503; повтор после reload использует тот же ключ |

Для повторного прогона `post_retry` перезапустить тестовый сервер. Журнал
`artifacts/frontend/fixture-requests.jsonl` содержит фактические payload и ключи.
При ошибке отправки можно отложить запрос, изменить параметры и восстановить
исходный запрос из истории. Проверить сохранение ключа и payload.

Дополнительно проверить: ручные координаты, прямоугольник и полигон; изменение
дат убирает устаревшие результаты; справку и скачанные JSON/GeoJSON; восстановление
истории; мобильные вкладки при ширине 390 px. Геометрия из четырёх вершин должна
передаваться как Polygon, а не заменяться ограничивающим прямоугольником.

## Реальный сервис

Запуск сервиса и входные данные описаны в основном README. Для приёмки нужны
готовая модель и геопривязанные train-сцены из каталога. Проверить BS и AF через
интерфейс, затем открыть скачанные артефакты. Тестовый стенд не доказывает качество
модели, доступность релизного URL или работу реального inference.
